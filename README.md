# DevOps Webhook Pipeline

This project demonstrates a basic CI/CD pipeline using:

- Git
- GitHub
- Jenkins
- GitHub Webhooks

## Pipeline Flow

Developer
    ↓
Git Push
    ↓
GitHub
    ↓
GitHub Webhook
    ↓
Jenkins
    ↓
Checkout
    ↓
Build
    ↓
Test
